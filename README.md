# Փոքրիկի օրացույց

JavaFX հավելված՝ երեխայի տվյալների, աճի, հիշեցումների և նշումների համար։

## Գործարկել Windows-ում

1. Տեղադրեք JDK 21 կամ ավելի նոր տարբերակ։
2. Միացրեք ինտերնետը առաջին գործարկման ժամանակ։
3. Կրկնակի սեղմեք `run.bat` ֆայլը։ Այն ինքնուրույն կբեռնի Maven-ը և անհրաժեշտ JavaFX գրադարանները։

IntelliJ IDEA-ում բացեք նախագիծը որպես Maven նախագիծ և գործարկեք Maven-ի `javafx:run` նպատակը։

Հավելվածը բացելիս առաջինը կերևա երեխայի տվյալների էջը։ Ծննդյան ամսաթիվը ընտրելիս օրական տարիքը կհաշվարկվի ինքնաշխատ։

## Էլեկտրոնային նամակներ

Գրանցման հաստատման կոդերի և հիշեցումների նամակների համար կարգավորեք հետևյալ միջավայրի փոփոխականները.

- `CALENDARBABY_SMTP_HOST`
- `CALENDARBABY_SMTP_PORT` (սովորաբար `465`)
- `CALENDARBABY_SMTP_USER`
- `CALENDARBABY_SMTP_PASSWORD`

Հիշեցումներն ուղարկվում են նշված ժամին, երբ հավելվածը բաց է։ Օգտատիրոջ տվյալները պահպանվում են համակարգչի տեղային `~/.calendarbaby/accounts.dat` ֆայլում։
